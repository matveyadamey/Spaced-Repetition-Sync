# Spaced Repetition Sync

Сервис интервального повторения: карточки пишете в Obsidian, повторяете в Telegram.

Бот: https://t.me/SpacedRepetitionHASKBot

---

## Установка с нуля

1. Скачайте и установите [Obsidian](https://obsidian.md/).
2. Откройте настройки → **Community plugins** → включите сторонние плагины и установите **BRAT**.
3. На боковой панели нажмите на появившийся значок BRAT — откроется меню.
4. Выберите **Add a beta plugin for testing**.
5. В поле **Repository** вставьте:

```text
https://github.com/matveyadamey/Spaced-Repetition-Sync
```

6. В **Select a version** выберите **latest**.
7. Нажмите **Add plugin**. Плагин установится.
8. Откройте настройки → **Сторонние плагины** → **Spaced Repetition Sync** и включите его.
9. Откройте Telegram-бота сервиса, отправьте `/start`, затем нажмите `Получить токен`. Бот покажет токен **один раз** — сохраните его.
10. Вставьте токен в поле **Token** в настройках плагина **Spaced Repetition Sync**.
11. В поле **Delimiter** укажите разделитель между вопросом и ответом (по умолчанию `::`).
12. Создайте карточки (формат см. ниже).
13. На боковой панели нажмите `>_` (командная палитра).
14. Откройте заметку с карточками.
15. В поиске введите «отправить карточки» и выберите **Отправить карточки на сервер**.
16. Выберите колоду (или **+ Добавить колоду** / **без колоды**).

Настройка завершена. Синхронизируется только **открытая** заметка.

---

## Формат карточек в Obsidian

В любом Markdown-файле:

```text
Что такое Python? :: Язык программирования
```

Или многострочно:

```text
Что такое Python?
::
Язык программирования.
```

Карточки разделяйте пустыми строками. В тексте **вопроса** обязательно должен быть символ `?`, иначе строка не считается карточкой.

После правок снова выполните **Отправить карточки на сервер** из открытой заметки и выберите колоду.

## Команды Telegram-бота

Управление ботом происходит посредством кнопочного меню.

| Кнопка | Что делает |
|---------|------------|
| `/start` | Приветствие и краткая инструкция |
| `Получить токен` | Новый токен для плагина (показывается один раз; старый сразу перестаёт работать) |
| `Повторить карточки` | Повторение: выбор колоды → вопрос → ответ → оценка |
| `Управление колодами` | Открывает меню колод (тем карточек) |
| `Статистика` | Просмотр статистики: всего карточек, к повторению сегодня, повторено сегодня, изучено % |
| `Сброс прогресса` | Удаляются данные о повторениях, карточки остаются; нужно подтверждение кнопкой |
| `Настройки` | Открывает меню настроек |

Меню колод:
| Кнопка | Что делает |
|---------|------------|
| `Мои колоды` | Список колод с количеством карточек в каждой |
| `Добавить колоду` | Запросит название колоды и добавит ее в список, далее можно из obsidian загружать в нее карточки |
| `Удаление колоды` | карточки переходят в «без колоды» |
| `Сменить колоду карточки` | Запросит **вопрос** на карточке, колоду которой хотите сменить. Потом кнопками можно выбрать новую колоду из доступных.|
| `Экспорт колоды` | Экспорт колоды в Markdown-файл (разделитель `::`), для бэкапа или для шэринга другим пользователям |

Ежедневный цикл: правите карточки в Obsidian → синхронизируете → в Telegram `Повторить карточки`.

## Уведомления
Если с времени последнего повторения прошло более 24-х часов бот пришлет напоминание.
Его можно отключить как по кнопке под уведомлением, так и в настройках.
