# Руководство пользователя

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте бота и сохраните токен для администратора сервера.
3. Найдите своего бота в Telegram и отправьте `/start`.

## 2. Получите токен плагина

Отправьте боту:

```text
/token
```

Бот покажет токен **один раз**. Сохраните его. Повторно посмотреть нельзя — только сгенерировать новый (старый сразу перестанет работать).

## 3. Установите Obsidian-плагин

### Вариант A — через BRAT (с автообновлениями)

1. Установите community-плагин **BRAT**.
2. Команда палитры: **BRAT: Add a beta plugin for testing**.
3. Укажите репозиторий:

```text
matveyadamey/Spaced-Repetition-Sync
```

4. Выберите **latest**.
5. Включите **Spaced Repetition Sync** в списке плагинов.

### Вариант B — вручную

1. Возьмите из GitHub Release файлы `main.js`, `manifest.json`, `styles.css`
   или соберите плагин локально.
2. Создайте каталог:

```text
ВашVault/.obsidian/plugins/spaced-repetition-sync/
```

3. Скопируйте туда три файла.
4. В Obsidian: Settings → Community plugins → включите **Spaced Repetition Sync**.

## 4. Настройте плагин

| Параметр | Что указать |
|----------|-------------|
| Token | Токен из `/token` |
| Server URL | HTTPS URL сервера, например `https://your-app.example.com` |
| Delimiter | Разделитель вопроса и ответа, по умолчанию `::` |
| Automatic synchronization on startup | По желанию |

## 5. Создайте карточки

В любом Markdown-файле vault:

### Однострочный формат

```text
Что такое Python? :: Язык программирования
```

### Многострочный формат

```text
Что такое Python?
::
Язык программирования.
```

### Несколько карточек

Разделяйте карточки пустыми строками:

```text
Что такое Python? :: Язык программирования


Что такое TCP? :: Протокол транспортного уровня.
```

### Важно

В тексте **вопроса** до разделителя должен быть символ `?`.

| Валидно | Невалидно |
|---------|-----------|
| `Что такое Python? :: ...` | `Что такое Python :: ...` |

Без `?` строка не считается карточкой.

Одинаковые вопросы в разных файлах считаются одной карточкой.

## 6. Синхронизация

Командная палитра Obsidian → **Отправить карточки на сервер**.

Успешный результат:

```text
Синхронизация завершена.

Добавлено: 5
Обновлено: 2
Удалено: 1
Ошибок: 0
```

Типичные ошибки:

- нет соединения с сервером — проверьте URL и интернет;
- неверный токен — получите новый через `/token`;
- ошибка сервера — повторите позже.

Синхронизация **зеркальная**: карточки на сервере становятся такими же, как в vault. Удалённые из Obsidian карточки удаляются и на сервере вместе с прогрессом.

Прогресс (интервалы, оценки) в файлы Obsidian **не записывается**.

## 7. Повторения в Telegram

```text
/review
```

1. Бот показывает вопрос.
2. Нажмите **Показать ответ**.
3. Оцените: **Сложно** / **Средне** / **Легко**.
4. После всех карточек сессия завершится.

Статистика:

```text
/stats
```

Смена разделителя (для плагина используйте тот же в настройках):

```text
/set_delim ::
```

Сброс прогресса (карточки останутся):

```text
/reset
```

Потребуется подтверждение кнопкой.

## 8. Рекомендуемый ежедневный цикл

1. Добавьте или правьте карточки в Obsidian.
2. Синхронизируйте.
3. В Telegram выполните `/review`.
4. При необходимости смотрите `/stats`.
